# Multiple Disease Prediction (MDP)

An academic project focused on developing a Django-based hospital website with multiple disease prediction functionality using machine learning.

## Project Overview

The project combines hospital website features with machine-learning-based disease prediction. It aims to provide patients with access to hospital information, user authentication, appointment scheduling and disease prediction functionality.

The system uses patient-provided data and trained datasets to predict possible diseases.

## Key Features

- Patient registration and authentication
- Multiple disease prediction based on patient input
- Hospital and doctor information
- Appointment scheduling
- Patient information management
- Hospital services and information pages

## Technology Stack

- **Programming Language:** Python
- **Backend Framework:** Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap 4, jQuery
- **Database:** SQLite3
- **Machine Learning:** Scikit-learn
